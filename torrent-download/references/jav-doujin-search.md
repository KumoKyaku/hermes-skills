# JAV & Doujinshi Search Reference

## Sukebei.nyaa.si
Primary source for JAV and doujinshi torrents. Requires mihomo proxy.

**URL:** `https://sukebei.nyaa.si/`

**Search parameters:**
- `q`: query (URL encoded)
- `f=0`: no filter (include all)
- `c=0_0`: all categories
- `s=seeders&o=desc`: sort by seeders descending
